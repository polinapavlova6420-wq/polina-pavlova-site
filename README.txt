Публикация на Vercel:
1. Создайте новый проект в Vercel или откройте существующий.
2. Загрузите папку проекта целиком в GitHub-репозиторий.
3. Импортируйте репозиторий в Vercel.
4. Framework Preset: Other; Build Command и Output Directory можно оставить пустыми/по умолчанию.
5. После Deploy проверьте обе ссылки Cal.com и Telegram.

В проекте сохранены текущие ссылки записи:
https://cal.com/polinapavlova.ru/индивидуальнаяконсультация

Перед публикацией проверьте актуальность цен, условий оплаты и описания профессиональной квалификации.
